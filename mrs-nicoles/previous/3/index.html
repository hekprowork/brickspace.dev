小如的小白花

9/11/2016

0 評論

 
學琴半年的小如
目前是個孕媽媽
平常除了要上班外還要照料四歲的兒子 
為了兒時夢想  擠出時間來學琴練琴 
真的很不簡單！

巧瑜參加史坦巴哈盃音樂比賽﻿

7/23/2016

0 評論

 
四月多時
小二的巧瑜突然心血來潮
跟我說她想要參加音樂比賽
當時正在準備五月的音樂會曲目
看看距離比賽只剩不到兩個月
蠟燭真是兩頭燒
由於考量到音樂會的曲目如果當作比賽曲目可能程度不太夠
於是我當機立斷選了一首短小精采的曲目 莫札特奏鳴曲k.545的第三樂章
這首程度符合 長度也不會太長
積極的巧瑜練琴速度快也很認真
於是六月中在台北區的比賽順利的進入了全國賽
大約三個禮拜後
以同樣的曲目參加台中的全國賽
這三個禮拜裡面 我們針對重點區域 將16分音符的部分彈得更清楚
還有加強強弱音色變化 
最難的是 上述條件都兼顧的情況下 速度再往上調升許多
影片是全國賽當天在琴房練習的情況（不曉得為什麼聲音跟畫面之間有點lag）

內容聽起來滿好的～
​

可惜比賽現場
幸運的巧瑜抽到一號
可能太過緊張的她 居然失誤了
聽說掉了很多音 真的非常可惜！
結果最後成績拿到小二組全國第九名 

不過 比賽就是這樣
誰最穩定 誰就是贏家！

其實 每次的比賽 重點都是讓學生獲得寶貴的經驗
還有心態一定要正確
成績！真的不是那麼重要了喔！

仔仔的鄉村舞曲﻿

7/12/2016

0 評論

 
仔仔的個性開朗活潑
音樂會我特別選了一首適合他的鄉村舞曲
不過這首的中間段落節奏比較複雜
加上高把位的音準也比較難
所以對仔仔來說也是一個大大的挑戰
其實在音樂會前兩週仔仔都還沒練到能上台的程度
因為仔仔很優秀 校內校外的外務實在太多
也壓縮到練琴的時間
於是我很認真的請他考慮是否要繼續學琴
突然 下一週來 我發現他突然進步了！
而且他跟我說他是發自內心地想要練琴
最後兩週仔仔卯起來練習
於是整個鄉村舞曲都活過來了！

可惜的是  音樂會上很明顯能感覺仔仔的緊張
於是演奏起來音樂有點怕怕的
不然仔仔平時演奏起來可是如同他的個性一般
自在與自信 身體還會跟著搖晃呢～

不過 整體來說還是滿不錯的！
（中間段落拉錯弓法和節奏還能從容不迫的繼續拉下去！）
還是要說 充分的練習才能成就完美的演出！
下次別在最後兩週才覺醒啊！！

﻿孩子學鋼琴需培養的基本功

6/23/2016

0 評論

 
最近看到一篇寫的非常好的文章!跟大家分享一下~
不同的是 我都是用{橡皮擦}訓練法喔!!
​
........................................................................................................................................................

基本功猶如高樓大廈的地基，萬丈高樓平地起，靠的是堅固的基礎，大廈的高度決定於基礎的堅固程度。鋼琴學習也是如此，基礎打不好，注定前途暗淡辛苦！
孩子學鋼琴需培養的基本功應包括彈奏技術和思想藝術兩大方面。
♪　　彈奏技術方面：
　　一、手型
1、自然的圓拱型 ;
2、手指站立，不塌 ;
3、手腕“沉到底” ;
4、手腕不顛。
　　二、手指
1、“落”的時候手指挺立 ;
2、“滾”的時候手指不要過分高 ;
3、連線中間各音手指要盡力抬高、下鍵不宜過重，
做好手指間力量轉移 ;
4、下鍵到底 ;
5、貼鍵敏捷 ;
6、大跳準確 ;
7、哈農慢速有力，快速均勻，左右手對齊。速度根據發展方向
不同可達每分鐘60~120拍。
　　三、控制
1、直立式鋼琴音量層次不少於6個 (pp、p、mp、mf、f、ff)，
平台式鋼琴音量層次不少於8個 (ppp、pp、p、mp、mf、f、
ff、 fff) ;
2、直立式鋼琴音色層次不少於5個 (暗、中暗、中、中亮、亮)，
平台式鋼琴音色層次不少於7個(極暗、暗、中暗、中、中亮、
亮、極亮)。
　　四、放鬆
1、下鍵後立即放鬆，手腕“沉到底” ;
2、手肘不僵硬 ;
3、不聳肩。
　　五、常規音色
飽滿、結實、鬆弛、圓潤。
♪ 思想藝術方面：
　　一、音樂素質
1、對音高的分辨能力，能唱準、聽辨出基本音級、變化音級及
常用音程和和弦 ;
2、對節奏的分辨能力，能判斷出節拍、節奏的差異，內心節奏
穩定 ;
3、對強弱層次敏感，遵守節拍的強弱規律，兼顧旋律起伏和音樂
表情記號 ;
4、具有豐富的鋼琴音色鑑別能力。
　　二、藝術素質
1、熟悉中外音樂經典旋律 ;
2、了解本國民族民歌、民間音樂、戲曲、曲藝等 ;
3、對相關藝術例如美術、攝影、文學、詩歌等有 
了解。
　　三、人文素質
1、關心世界前途和國家命運 ;
2、關心身邊人的喜怒哀樂 ;
3、關心自然、關心環境 ;
4、感情豐富，富於同情心。
掌握鋼琴的兩個方面基功的訓練和培養，才能使孩童得到均衡發展，有效地保證琴童學有所成。我把兼顧兩方面的發展，稱之為平均使用雙腿走路。
現今孩子學鋼琴最容易忽視的是第二方面，即思想藝術方面的修養和發展，若只顧發展技巧，技術雖然在短期內到達了，但使琴聲缺乏應有藝術性而陷入蒼白，這種單條腿走路顯然是不協調的，反倒限制了孩子的發展。
PS. 圖片說明：
克萊曼第 Muzio Clementi (1752-1832) 與其著名的『硬幣練琴法』
克萊曼第在鋼琴技巧上最有名的理論是叫學生在手背上放一枚硬幣練琴的做法，如果硬幣掉了，就是手的姿勢不對，而且錢幣必須停留在手背上直到完。他認為手指操縱一切，擁護主動活躍的手指和絕對固定不動的手。手要保持安定(這個理論跟當時代的鋼琴構造有所關聯)。
當然，要是在現今的年代這樣彈琴，聲音會極其單調僵硬且乏味。

佐佐的第一號﻿巴哈無伴奏前奏曲

6/18/2016

0 評論

 
學習大提琴的大小朋友們
聽到廣告名曲---第一號巴哈無伴奏前奏曲
總是非常喜愛且躍躍欲試！
不過通常要學習到一個程度著手這個樂曲才不會音色卡卡
我去年開始訓練佐佐練習巴哈無伴奏
主要是因為他的長音（長弓）總是捨不得拉開
手臂也伸展不開！
其實姿勢是不錯 但是總是懶得照規矩練習空弦及長弓
於是在正常的練習曲之後 我便用巴哈這首前奏曲來訓練他
每次練習四個小節 慢慢的累積...

但是演奏這首除了右手要穩定外 左手音準和換把位也必須要有一定的技巧
所以我們除了一次四小節外 還先全部分弓練習！
準備這場音樂會曲目時
我讓他用四個音一弓來詮釋！

當然！非常多的時後,因為樂曲難度,他也幾度想要放棄！
但是我必須說,練習過程中他真的進步很多！
連音色也比小時候的他還放鬆許多！
好笑的是 演出當天佐佐因為緊張
因此演出的時候頭不自覺得往上伸展抖動
音樂會後有不少人問我 老師：你兒子音樂會上的動作是有什麼特別的涵義嗎？！
哈哈！！其實他只是緊張的舒緩動作而已啦！

偲暟的演出

6/15/2016

0 評論

 
感情豐富的暟暟
每次演出抒情的樂曲總是音樂性十足
尤其是之前他演出自己喜愛的樂曲 那些年 或 童話  
彷如情歌王子
但今年我想要讓他挑戰困難一點的樂曲----塔朗泰拉舞曲
這首樂曲的技巧和節奏都對偲暟來說都是挑戰
尤其是68拍的拍點掌握 還有高把位的音準
一直到了演出的前一週暟暟才比較上軌道
原本我還想是不是就放棄演出這首好了！

暟暟的肌力比較不足
又因為緊張  所以緊盯著樂譜（其實他早就背好了）
音樂性被僵硬消掉了一些
而且比較可惜的是氣勢沒有拉出來
這首曲子長達四分半  其實是很不簡單的曲目
哈哈！看他拉完快要虛脫樣 不曉得是不是肚子餓了呢？
暟暟順利完成了這個演出 我還是給他大力讚賞和鼓勵喔！！

演出當天，雖然妹妹有點小小小出錯，但是，誰在乎！
完完全全曲如其名「快樂的早晨」！好愛好愛這組演出的感覺啊！

美魔女的卡龍

6/4/2016

0 評論

 
Denise小姐學琴約兩年左。

當我們開始為今年音樂會準備選曲，她提議到有兩首屬性不同的樂曲「卡農」與「龍貓」，是否可以結合在一起？
接著我們就開始編排、組合、討論，將之命名為『卡龍』。前面段落柔美，後面段落俏皮可愛，組合起來卻毫無違和。

D小姐由於工作的關係出國三個星期，音樂會前一週才回到台灣，缺少時間練習的他，直嚷嚷壓力很大，在台下等待也抓緊時間練習，表情相當嚴肅XD

上了台略顯緊張，右手稍微僵硬與前面段落跑了些音準，但是整體感覺值得讚賞，尤其前面段落情感融入，後面心情稍微放鬆，龍貓的輕鬆可愛效果也表現出來，滿可愛的！

熱愛大提琴的美魔女～明年也要繼續加油喔！
