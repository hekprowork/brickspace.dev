音樂會推薦~~~~楊善扉鋼琴獨奏會

0 評論

 
從台北飛車家教轉型小小家裡蹲工作室的初創時期，善扉是最早期幾位鋼琴學生之一。認真與天真集於一身的她，自小就在琴鍵上展露天份。認真對待老師的提點，不懈練習，讓他走上音樂班這條路。寒暑期間也沒閒著，常回來找我加強。

優秀的善扉，目前就讀師大附中國中部音樂班，為了更遠的理想，每天通勤也甘之如飴。

上週善扉與媽媽專程為我送來一張邀請卡

「楊善扉第一場個人音樂會」，這是八年級的勇敢挑戰。

與他們談到目前階段的學習、班上的氛圍與未來的規劃。很開心善扉在爸媽的支持下，有優秀的同儕陪伴，快樂地學習與成長。

細細端詳這張邀請卡，小時後對自我要求很高、從不需擔心會不認真練琴、幾乎每次上課都能得到最高獎勵五個印章，小善扉的一幕幕讓我禁不住微笑。

為人師不是只有變老，也會驕傲的^^

老師相信這場演唱會，善扉會穿上她從小最嚮往的美美演出服，毫無保留的演奏給你們聽！

108年基隆市音樂比賽

12/26/2019

0 評論

 
水深火熱的十一月份，經歷了幾個學生的市級音樂比賽。

長達四個月的時間，小選手們平日要應付學校課業與生活大小事，還要分心準備比賽，時間越接近，更須加強練習與賽前衝刺，心理壓力自然不小。

這次我有三個學生參賽。首先要肯定三位敢上台的學生。

因為這個比賽必須先準備大會公佈的三首難度不小的「指定曲」和一首「自選曲」，比賽前15天才會確定大會抽出哪一首指定曲。光是三首未定的指定曲，小選手就必須花很多心力背譜練習。能駕馭指定曲這個最低門檻，才能有機會上台比賽。沒有三兩三，豈敢上梁山。

比賽結束，選手們各自收穫不少，尤其體會「台上一分鐘，台下十年功」的真理。

影片是這次參加基隆市音樂比賽國小B組鋼琴獨奏的學生。獲得甲等第三名，平均成績84.8 。

她本來就算是台風穩健，熟練度破表的學生，上台後仍然不免肌肉僵硬，導致部分快速音群沒有清楚呈現。甚至出現幾個從來沒聽過的錯音@@ 

台上在實力相差不遠的情況下，比的就是穩定性。

多數評審給予她「音樂性佳」的評語，也算是實至名歸喔！

“孩子不喜歡彈就別逼他”，別讓這種話害了孩子一生

12/26/2019

0 評論

 
​作者 | 憑闌
來源 | 每日優教
週末，朋友來家裡做客，趕巧遇上兒子練琴。
坐在鋼琴前的兒子一臉不情願，一首簡短的曲子還未彈完，就開始找各種藉口逃避練習。
這是他慣用的伎倆，當然我不會吃這一套。
兒子雖然又哭又鬧，但在我的堅持和擁抱安撫下，最終還是坐回了琴凳上，眼中含淚練習當天的曲目。
朋友看不下去了，對我說了開頭這一句話，建議我別逼孩子，應該選一件他喜歡的事情讓他做，學習才能事半功倍。
●喜歡是本能，喜新厭舊也是本能
讓孩子練習鋼琴並不是我的意願，而是孩子自己的選擇。
有天路過琴房，看見裡面擺放的黑白鋼琴，孩子駐足望了好久，然後拉著我的手說喜歡，想學鋼琴。
我當時只當是孩子一時玩笑話，並沒有留意。
隨後的時間裡，看見孩子模仿電視上鋼琴演奏家彈琴的模樣，我決定幫他實現他口中的「喜歡」。
從一開始的認真、熱情，到兩個星期後的抗拒，孩子對鋼琴已經失去了一開始的興趣。
所以才會出現我「逼迫」孩子的一幕。
「媽媽，我發現我不喜歡鋼琴了，我更喜歡小提琴。」
面對孩子不斷變換的喜歡，我是否應該選擇妥協？
不！
我深刻地知道，即使我現在安排孩子學小提琴，放棄鋼琴，指不定什麼時候，孩子還會對我說：「媽媽，我不喜歡小提琴，更喜歡某某。」
喜歡是人的本能，但同時，喜新厭舊也是人的本能。
孩子今天說喜歡這個玩具，明天看見別人手裡的玩具，發現自己好像更喜歡別人的。
如果父母一味縱容孩子的「喜歡」，任由孩子在「本能」中成長，未來成功的可能性有多少呢？
喜歡是人的本能，但是本能不是技能，如果凡事按照本能走，那麼人人都可能是失敗者。
為人父母，不應是縱容孩子的本能，而是應該想著如何將本能變成孩子的技能。
●弱者只談喜歡，強者都談堅持
教育的最終目的是什麼？
讓孩子成為一個優秀的人，相信這是大部分人的回答。
而優秀的人都有一個共同的特點，他們都是某個行業，某個領域，甚至為人處世上的「強者」。
社會很現實，也很殘酷，弱肉強食的社會裡，更多時候不是適者生存，而是強者生存。
要想孩子不被殘酷的現實淘汰，就要教育孩子如何成為一名強者。
而強者最大的品質就是：堅持。
強者不會因為一句不喜歡，就否認掉自己的努力，就不作為。
好比如你去隨機採訪一名學生，詢問他喜不喜歡上學，相信大多數孩子的真心話都是「不喜歡」。
既然不喜歡，為何還要繼續呢？
不可避免，其中有父母的「逼迫」，但更多的孩子心中卻很明白：不喜歡，但是必須堅持，因為讀書是自己當下所能選擇的最直接的出路。
那麼多學霸的成功，大部分不僅是喜歡學習，而是堅持學習。
周杰倫曾透露，正是因為媽媽葉惠美「逼迫」自己從小堅持練習鋼琴，才成就了如今的周天王。
強者講的是堅持不懈，而不是喜歡與不喜歡。
要想孩子將來有所成就，父母就要教會孩子如何去堅持自己的「喜歡」。
●最大的遺憾不是「我不行」，而是「我本可以」
很多父母覺得，孩子應該有一個快樂的童年，孩子還小，應該讓他開心快樂地成長。
因此，孩子身上的特點，無論好與壞，父母都理所應當地將其歸為天性，似乎都具有天然的合理性，不可辯駁、不可壓制。
「孩子嘛，就應該快樂地成長！」
為人父母，誰不想讓孩子快樂地成長？
我們不否認快樂教育和釋放孩子天性，的確讓一些孩子充分發掘出自己的天賦，並且在興趣的驅使下，快樂地堅持下去，這是皆大歡喜的結局。
但是，當我們的孩子，還分不清「喜歡」和「喜新厭舊」，不懂得「半途而廢」和「堅持到底」會帶來的巨大差距，我們是否要一味縱容他的性子，讓他按自己喜歡的來呢？
沒有人生來就喜歡吃苦，喜歡安逸、享受是人的天性。
但恰恰學習本身就是一個吃苦的過程。
如果一味讓孩子選擇自己喜歡的方式成長，沒有哪一個孩子會主動選擇學習、吃苦、堅持，大部分孩子只想要舒舒服服。
一旦父母「縱容」孩子的想法，讓他用喜歡的方式長大，當年一時爽，餘生幾多殤。
不要等別人的喜歡變成了堅持，本能變成了技能，再來後悔：我本可以。
不要等面臨人生窘境的時候，才回過頭來抱怨人生，埋怨父母當時對自己放養，不管不顧。
●有遠見的父母，都捨得讓孩子吃點「苦」
孩子小，本身認知能力不足，無法判斷事情的好壞，是否對自己的將來有害。
這時候，父母就必須起到引導作用，推孩子一把，先苦後甜，讓孩子的未來更有保障。
都說有遠見的父母，都帶點心狠。
適當地「逼迫」孩子學習，而不是縱容孩子用他現階段喜歡的、舒服的方式成長，其實是對孩子將來的負責。
如果按照孩子的本能，任由孩子用喜歡的方式成長，就像提前埋下的地雷，總有一天會以悲劇收場。
有遠見的父母，確實都有點狠心。
「逼迫」孩子堅持去做一件事情，強迫孩子去學習他現階段不喜歡的技能。
但技多不壓身的道理，誰都清楚，只是有些人選擇忽視，覺得孩子喜歡更為重要，到頭來什麼都不會的孩子反倒埋怨起父母。
而有些父母選擇實踐，往往在孩子搖擺不定的時間裡，就已經幫助孩子學會了堅持，掌握了技能。
如果要想毀掉孩子的未來，就大膽地讓孩子只用他喜歡的方式過一生。
如果真為孩子好，父母就要有一點心狠，適當地「逼」孩子一把。
在他想要放棄時，幫助他學會堅持，
在他喜新厭舊時，教他不要半途而廢，
這才是對孩子的未來負責任。


以上文章轉貼自Fan-Chiang Yi 范姜毅臉書

開心獲獎的十月

10/30/2018

0 評論

 

十月份，兩組學生分別參加了兩場音樂比賽。

分別是參加里拉傑人盃的兄妹檔古典鋼琴四手聯彈，另一位參加捷克波希米亞都會盃非音樂班國小中年級鋼琴獨奏。

於是接連兩週末，line上面都傳來學生手握獎盃的照片，真高興！

​
兄妹四手聯彈的曲子是"Anton Arensky的Marchen op. 34"

樂曲速度自由活潑，需要大量的音樂性，十足考驗兩人的默契。
這首曲目兩人已在五月的音樂會上表演過，休息幾個月沒繼續練習。賽前一個月，兄妹非常認真的重拾記憶，琢磨演繹。

賽前意外出現插曲：兄妹與家長現場才知道要背譜比賽XDDD

印象中之前參加的比賽，四手聯彈不需要背譜，曾關注的國際四手聯彈大賽，也都沒要求背譜，以至於練習過程中，即使他們早就已經背起來，我也沒要求兄妹背譜演奏。

沒有再三確認簡章，老師要去面壁思過XD

還好兄妹倆很給力啊！

在無法熱身的突發狀況下，還是完整彈完整首樂曲。不過哥哥應該有驚到，稍微不穩；平常彈地非常煽情，比賽中音樂性沒有完全表現。

倒是妹妹非常淡定，演出表現非常優異！

最後她們拿到86.2的成績，獲得了第一名，非常開心！
10月28日，捷克波希米亞都會盃音樂比賽，妏妏參加非音樂班中年級古典鋼琴組獨奏。

參加比賽的決定很倉促。

當時深美小小弦樂團正在練習「德布西」的「小黑人」。

鋼琴課時，心血來潮的我拿出鋼琴譜，讓妏妏也練習這首樂曲，沒想到妏妏展現高度興趣，練習進度飛快。九月中才開始練習這首樂曲，十月初她就完成基本雛型。

隨口問妏，來參加比賽好不好？隨便選一個最接近的比賽，然後全力衝刺！

妏妏很快便答應！只問我：得獎有沒有禮物？XD

接下來，很快的練習德布西一定要用到的延音踏板與柔音踏板，這是她必須重新學習的技巧，並不斷練習了她最欠缺的音樂張力（強弱變化）。

可愛的妏在音樂技巧上，只要我要求，他都能充足表現。唯獨因為害羞，讓音樂性頗佳的她，常刻意壓抑音樂表現，這正是我藉由這次比賽，想導正的重點。

一步步慢慢的進步，月底很快的到來。

比賽前三天，一切大致順利的妏，竟然開始彆扭喊著：

為什麼要敬禮？為什麼要吸氣？為什麼要延長？為什麼這邊要漸強？我不想表現強弱！

我生氣又無奈的說：那就不要比賽好了（激將法）

————————冷靜分隔線———————————--

有些孩子真的急不得，與媽媽溝通過後，冷處理她。一直到比賽前一天，請媽媽帶妏妏來讓我聽一下。針對她可以立刻練起來的部分，簡單指導調整。妏果然韌性十足，先前的扭捏感不見了，更多了些自信和音樂性！

比賽當天下午，媽媽傳來比賽實況：有緊張不小心漏掉音，有肢體僵硬讓強弱無法完整呈現，切分音不夠精確等小毛病。

但記得上次比賽，妏妏的跳音被評審嫌棄。這次比賽前特別跟妏說，「德布西」跳音很多，一定要修正跳音技巧，不然一樣逃不過扣分～～

賽後從評審的評語，大部分稱讚她的台風、踏板踩的確實乾淨、聲音清楚分明，沒有任何有關跳音的負評！太棒了！
最後成績，總分87.33。
十個參賽者，妏獲得了第四名，與第三名的差距0.3分。開玩笑說就如果沒漏掉那個音，就第三名了囉＾＾
其實對老師我來說，名次不是很重要，最大收穫是學生從比賽中獲取的進步，得到了自信與難得的經驗，還有我們一起努力的成果（音樂和禮物）！

襄兒陶醉於音樂

12/28/2017

0 評論

 
蔡襄襄
目前學琴十個月
前兩週遇到一個瓶頸
視譜原本很順利的她
突然失靈了 ！
​原來最近進度開始有點難度
在一首曲子裡 除了大譜表外 高低音譜記號也不停的交錯出現
除此之外 左右手還要交叉彈奏
然後 又是需要放鬆觸鍵才能彈得好的技巧---跳音
於是可愛的襄襄 開始拿出耍賴功夫 還有掉淚的伎倆

寫在音樂會後

6/10/2017

0 評論

 
寫在音樂會後
今天早上吞下七天抗生素流程的最後一顆藥，回想這個月來我的身體持續的虛弱狀態。
首先，遭遇半年前預訂好且已付全額的音樂廳場地因為一例一休政策影響，臨時取消（五月才通知我啊啊啊）我計畫六月初的音樂會場地，無奈只能緊急尋找北區其他音樂廳。
但適合的場地早已都被預訂，洽詢過程中還不停都被問「下個月要演出你現在才找場地？」
經過一番折騰討論，試想延期？延到秋季淡季，學生又要折磨很久！改期？改前改後都有人出國月考無法參與！一度想取消算了？但想到大家辛苦都白費了...
於是只能在不變日期的原則下，繼續努力尋找場地，那一週我天天在連絡場地...
所幸我的老師歐陽伶宜幫忙牽線昨天的場地，加上還有偲愷媽媽的協助，才能裡應外合，讓原則不外借的演藝廳同意租借給我們，接著經過一番功夫，終於在演出的前一週拿到收據，心中的大石頭才得以放下！
期間，想不到病毒也來參一腳.....一開始是腸胃炎，俗稱腸胃型感冒，連續發燒多天，很慘..
好沒一個禮拜，又遭逢類流感，雖然急診快篩不是AB型流感，但發燒、畏寒、全身痠痛、食不下嚥，該有的症狀一個都沒少。 微微發燒38度連續七天，覺得自己身體很虛，快燒壞了！
每天耳溫槍不離身，一直被提醒是否直接去辦住院徹底檢查？好不容易週末感覺自己好了，過沒兩天，馬上又中了感冒，又開始低燒....
醫生診斷病毒轉成細菌感染，開始吃抗生素治療（每次都是週末身體比較好，週一病毒就又來 該死的病菌也有周休二日嗎）。一個月內，經歷了三次門診、一次急診，躺在瀰漫各種氣味的急診室走廊吊點滴。
很多人問我為什麼不請假？其實偷偷請假過幾次，身體真的撐不了！
可是想到音樂會在即，一個禮拜只上一次課的學生怎辦？拖過一週進度落後壓力更大，又不可能有時間補課，只好一直硬撐著上完課，一下課立刻昏倒。為了保護大家也保護我自己幾乎失效的免疫系統，所以這個月很多人看到我幾乎都口罩見人，身體無法再承受其他喊不出名的小小病源。
這陣子完全吃不下，整整瘦了兩公斤。期間，曲目編排、心得催繳、節目單校對、製作，一刻不能停，但更慘的是，不停的吃藥，抗組織胺、類固醇，抗生素，昨天竟還是頂著嬰兒肥臉上台。
要不是發生計畫之外的變動，自2007開始連續舉辦十年的音樂會，不至於把我搞成成這副模樣，學音樂的人抗壓性不會這麼低。
還好音樂會超級圓滿成功！非常感謝全體工作人員，還有家人，全力的支持我。會後聽到大家的感想，無論是觀眾或是演出者，給我我滿滿的正向回饋
「老師～你的學生都進步好多！大家都很認真！程度都很好耶～～」
我知道，我的病，在6/11晚上，一定不藥而癒！
