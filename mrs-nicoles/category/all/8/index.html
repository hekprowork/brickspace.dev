佐佐的小星星

9/8/2012

0 評論

 
Enzo佐佐
是我的兒子
目前五歲三個月
今年我開始嘗試教他玩大提琴
我必須承認他是我教過最難搞的學生
我非常確定他很愛大提琴也很有興趣
但畢竟在他眼裡我是個媽媽
所以耍賴偷懶撒嬌發脾氣樣樣來!! 經過一連串的溝通引導與獎勵(當然少不了爭執) 
他終於完成了一首小曲子---小星星! 
這是他第一次完整的拉完一首曲子雖然音還有些不準  
但是我還是很感動!!

大提琴小公主---雅右

7/15/2012

0 評論

 

雅右是我收過最小的學生
使用的是八分之一的琴
剛來上課時她才四歲多 最近剛過五歲生日
聽媽媽說 來上課前她總是要自己挑衣服
每次都要穿的像新娘或是公主一樣!
非常可愛!

學習力很強的她 耐力也很不錯
才中班的她已經可以坐足一個小時
而且無論按弦 或是看譜都學習的很快
絲毫沒有比大哥哥大姊姊還遜色


不過 除了上課時間外
下課後的她完全變了樣
完全是皮蛋右一個
哈!!畢竟還是個小小女孩阿!!


這張是她上課認真的表情!
我很愛!!

孟瑀的校園比賽

5/1/2012

0 評論

 
我總是很鼓勵學生參加校內的演出甚至比賽
希望學生們有機會就能參與公開的演出~

有天孟孟告訴我她想參加學校天籟之音的比賽
於是我們一起想想她最近練的曲目
剛好當時我們正在準備台北市音樂比賽 
其中三首指定曲及一首自選曲都已練完成
所以我便從中選了一首 再精挑細改她的音色及缺點
大概認真練了兩週
孟孟一路從初賽到決賽
最後獲得了優等獎(第一名)
恭喜她~~

睿騏的校園才藝比賽

4/18/2012

0 評論

 
目前小二的睿騏
有天突然跟我說 他想參加學校舉辦的才藝比賽!!
然後他想用歲末音樂會的曲子直接參賽!

當時是一月份 距離音樂會結束時間不久
於是我並沒有特別去修飾這首樂曲
所以上課進度正常!!

過了幾週 他來上課時
突然他淡淡的跟我說
老師~~我比賽得了第四名!!
而且是跟哥哥姊姊一起比的(全小學部)
我忍不住大叫:真的嗎!?!好厲害!!

他只是靦腆的笑笑!!!

比賽成績本來就不重要!!
可是有勇氣參加比賽 而且成績還真不錯!!
老師我真的覺淂 睿騏好棒阿!!

2011音樂會開場---弦樂重奏

2/12/2012

0 評論

 
跟去年一樣我和賴老師一起籌劃音樂會
最主要的就是希望學習弦樂的同學能夠有合奏的演出
不管是小提琴或是大提琴 可以組合成一個弦樂團
然後共同演奏出優美的曲調!

於是我們今年增加了更多重奏曲目
並且在演出的前一週就集合練習 培養默契 
為的就是希望大家在台上能共同譜出動人的樂曲!

我們把弦樂重奏分別安排在上下半場第一個曲目
作為音樂會開場 
第一首是 母親您真偉大
第二首是 Joy to the world

這個團體最特別的是
成員的年紀最大是高一 最小只有幼稚園大班
而且練習時間雖短 但是彼此默契絕佳 
演出很成功!

2011音樂會---芷嫻的演出

2/11/2012

0 評論

 
芷嫻是譽凱的姊姊算一算她也才學琴一年三個月
但音樂會上她的台風及表現都是一副經驗豐富的樣子
我比較驚艷的事 平時練習時有些段落每練必錯 
令我非常擔心!!

沒想到音樂會上 那些小錯誤竟然全部安全通過了!!
表現的真的很不錯!!!
特別是那天穿的淑女樣 跟平常大剌剌的模樣真的差好多阿!
音樂會後 這兩姊弟真的詢問度很高呢!

第一次音樂會 成功!!
