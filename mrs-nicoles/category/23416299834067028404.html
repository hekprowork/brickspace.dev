108年基隆市音樂比賽

12/26/2019

0 評論

 
水深火熱的十一月份，經歷了幾個學生的市級音樂比賽。

長達四個月的時間，小選手們平日要應付學校課業與生活大小事，還要分心準備比賽，時間越接近，更須加強練習與賽前衝刺，心理壓力自然不小。

這次我有三個學生參賽。首先要肯定三位敢上台的學生。

因為這個比賽必須先準備大會公佈的三首難度不小的「指定曲」和一首「自選曲」，比賽前15天才會確定大會抽出哪一首指定曲。光是三首未定的指定曲，小選手就必須花很多心力背譜練習。能駕馭指定曲這個最低門檻，才能有機會上台比賽。沒有三兩三，豈敢上梁山。

比賽結束，選手們各自收穫不少，尤其體會「台上一分鐘，台下十年功」的真理。

影片是這次參加基隆市音樂比賽國小B組鋼琴獨奏的學生。獲得甲等第三名，平均成績84.8 。

她本來就算是台風穩健，熟練度破表的學生，上台後仍然不免肌肉僵硬，導致部分快速音群沒有清楚呈現。甚至出現幾個從來沒聽過的錯音@@ 

台上在實力相差不遠的情況下，比的就是穩定性。

多數評審給予她「音樂性佳」的評語，也算是實至名歸喔！

襄兒陶醉於音樂

12/28/2017

0 評論

 
蔡襄襄
目前學琴十個月
前兩週遇到一個瓶頸
視譜原本很順利的她
突然失靈了 ！
​原來最近進度開始有點難度
在一首曲子裡 除了大譜表外 高低音譜記號也不停的交錯出現
除此之外 左右手還要交叉彈奏
然後 又是需要放鬆觸鍵才能彈得好的技巧---跳音
於是可愛的襄襄 開始拿出耍賴功夫 還有掉淚的伎倆
還好我跟襄襄媽不停的鼓勵與激勵她
於是在第三週
襄襄終於可以完整的組合起整首樂曲
並且背譜演奏 
所以我立刻拿起手機紀錄這一刻～

​

同場加映
最近這週通過的臨時升降記號練習曲~歇腳石
可愛的襄襄彈起來顯得特別輕鬆愉快！

祝大家新年快樂喔～

善扉的進步

12/27/2016

0 評論

 
自從善扉三年級考上音樂班後
我們有幾次機會在寒暑假加強一些基礎課程
因為暑假通常善扉會參加比賽 我也能給善扉一些建議~

這次邀請善扉來參加演出
也想看看目前善扉的狀況
還有我特別喜歡看她在台上充滿自信的小臉
於是我沒時間聽她練習狀況 也就請她直接上台演出了!

老實說  音樂會上我也沒仔細聽她演出
因為後台一陣忙亂阿!

現在細看影片
覺得小時後彈琴手腕會晃呀晃的善扉 現在真的進步好多阿!
不過我還是要毒舌一下
第一首快速音群必須要乾乾淨淨 可能熱身不足 聽起來有些卡卡的
但音樂性佳!

第二手莫札特奏鳴曲
速度上必須再流暢些 可是速度加快的情況下技巧就必須練得更好
因為這首奏鳴曲全部都是由16分音符組成的 聲音要乾淨 但音色絕對不可以一粒粒的
然後重點是彈奏莫札特的奏鳴曲要能夠玩音樂 不可以沉重 不然旋律就會變得沉悶了
這全都跟基礎技巧有關 所以在音階的練習就非常重要了
音階不能只有練速度 還要練音色 音色 音色啊!(很重要所以說三次)

我怎麼好像變成音樂比賽的評審講評了!
沒錯 善扉當時打算用這首奏鳴曲去參加鋼琴比賽
我們音樂會後也找了機會修正了多處音色及觸鍵的問題
大概上了幾次課
一直到七月份參加文化盃音樂比賽
聽起來就已經流暢許多
整個音樂都飛揚起來了呢!

巧瑜參加史坦巴哈盃音樂比賽﻿

7/23/2016

0 評論

 
四月多時
小二的巧瑜突然心血來潮
跟我說她想要參加音樂比賽
當時正在準備五月的音樂會曲目
看看距離比賽只剩不到兩個月
蠟燭真是兩頭燒
由於考量到音樂會的曲目如果當作比賽曲目可能程度不太夠
於是我當機立斷選了一首短小精采的曲目 莫札特奏鳴曲k.545的第三樂章
這首程度符合 長度也不會太長
積極的巧瑜練琴速度快也很認真
於是六月中在台北區的比賽順利的進入了全國賽
大約三個禮拜後
以同樣的曲目參加台中的全國賽
這三個禮拜裡面 我們針對重點區域 將16分音符的部分彈得更清楚
還有加強強弱音色變化 
最難的是 上述條件都兼顧的情況下 速度再往上調升許多
影片是全國賽當天在琴房練習的情況（不曉得為什麼聲音跟畫面之間有點lag）

內容聽起來滿好的～
​

可惜比賽現場
幸運的巧瑜抽到一號
可能太過緊張的她 居然失誤了
聽說掉了很多音 真的非常可惜！
結果最後成績拿到小二組全國第九名 

不過 比賽就是這樣
誰最穩定 誰就是贏家！

其實 每次的比賽 重點都是讓學生獲得寶貴的經驗
還有心態一定要正確
成績！真的不是那麼重要了喔！

品言的獵人﻿合唱

1/29/2016

0 評論

 
品言是去年大約三月開始跟我上課的學生
因為參加了學校的國樂團開始學習大提琴
但是拉琴總是腰痠背痛 手腕手臂也都不舒服
所以媽媽找上我
希望我能把品言的姿勢跟基礎調整好

必須坦言
一開始看到品言的拿弓方式  還有按弦姿勢 我有點傻眼...
但其實各種形狀的姿勢我看多了  並不是因為姿勢本身而頭痛
而是覺得這樣的拿法 怎麼小朋友還能撐得住這麼久
要是我早就放棄了吧!因為實在太不舒服了!(應該只拉五分鐘就會手痠了)

要知道 改姿勢是最艱難與痛苦的事情
如果沒有毅力練習 根本是三年五年也改不起來!
開始上課後 經過長時間的調整
我們搭配練習曲與小曲
加上品言真的很認真與家長的配合督促
現在的姿勢真是好太多了!(不能說完美是因為小孩偶而還是需要調整)

這首獵人合唱充分的運用跳音與16分音符
​然後接觸到了第二把位
如果姿勢不好 是絕對無法輕鬆的發出悅耳的聲音的!

我猶記得品言從開始到現在  
這首樂曲 品言的整體表現 極佳!

2015的聖誕鈴聲

1/4/2016

0 評論

 
深美小小弦樂團自今年度開始，獲得一筆贊助大提琴樂器的基金，我們計劃以這筆資金，供應受贊助團員的「樂器費用」（包括體格變化的換琴需求，但不包括樂團課程學費），在公開招生後，三位分屬一年級、 二年級、三年級的三位女孩報名參與計劃。

雖然是團體班教學，基礎技巧傳授一樣不能馬虎。無論是持、運弓或音階，樣樣不能少。這班的女孩們也很願意配合時而嚴謹，時而瘋癲的教學課程，每週至少都能達成設定進度的80%。
就在她們接觸大提琴兩個月的時候，我編了個簡單版的聖誕鈴聲，我們一起決定在聖誕夜的前一天，把成果記錄起來。

​看著這段影片，才學兩個多月的她們，生澀及緊張皆有，但他們的表現已經讓很久沒有接手初學大提琴團體班的我，欣慰又驕傲起來！

贊助樂團的好朋友，看了這影片竟熱淚盈筐起來，直呼希望投入第二波贊助啊！

深美國小之輕鬆音樂分享會

12/7/2015

0 評論

 
學生常常會跟我說他們現在喜歡什麼曲子，例如最新流行歌曲、電影或卡通動畫主題曲，有時候會是情境音樂.....

想完成孩子演奏心儀的樂曲的心願，通常需要重新編曲以配合他們的程度。我幾乎是來者不拒，因為孩子們既然自己燃起學習動機，身為老師不能錯過，還得加柴添火啊！（笑）

十月份，看著三位深美小小弦樂團的男孩（剛好都是我個別課的學生）各自拉著他們喜愛並主動想練習的曲子，突發奇想，何不找一天集合所有深美國小個別課的學生，來辦個音樂分享會！大家跟同學們分享自己喜歡的音樂、正在練習的樂曲，最重要的，會後讓大家一起吃吃喝喝聊聊天、玩桌遊！

當天雖然是同樂音樂會，但每個學生都認真看待，盡力表演自己的曲目！會後更是欲罷不能的一起玩了一下午，原本可能未必熟識的孩子，未來在校園內相遇應該都可以相見歡吧！
​
很羨慕恬家的演出（媽媽與姊妹合奏加妹妹獨奏），非常喜歡這個畫面。
只學一個多月就興致勃勃的來參加演出的二年級佳宸寶貝。
從美國回來的五年級美麗小姊姊
台下很活潑，台上很有氣質的希希
自我要求超高的二年級巧瑜寶貝
熱愛電子音樂的佐佐
有如白馬王子的偲暟演奏那些年
會後爸媽喝咖啡，孩子吃零食玩遊戲同樂
更多的照片及影音都在這裡
1120同樂音樂會　　　
​歡迎大家點去觀賞喔!
